# 🚀 CA AI Tool Backend

An AI-powered backend system designed for Chartered Accountants (CA) to automate invoice processing, GST validation, financial reporting, and business insights using AI.

## 📌 Features

### 📄 Invoice Processing
- Upload PDF invoices
- Extract text using OCR
- AI-based invoice analysis
- Store invoice data in MongoDB

### 🤖 CA AI Copilot
- Financial summary generation
- Business insights
- AI-powered question answering

### 📊 Dashboard Analytics
- Total Invoices
- Total Revenue
- Total GST
- Paid Invoices
- Pending Invoices

### 🏢 Client Management
- Add clients
- View clients
- Store client details in MongoDB

### 🧾 GST Compliance Checker
- GST Rate Calculation
- Tax Validation
- Compliance Status Check
- Issue Detection

### 📈 Financial Reports
- Automated report generation
- Revenue analysis
- GST summary
- Business recommendations
